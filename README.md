RFID 카드리더기를 활용하여 카드체킹을 통한 출입통제기 구현

구현 기능
- RFID 모듈을 이용한 카드체킹
- 카드체킹이 되었을때 등록된 카드는 서보모터 동작
- 버튼상태를 통하여 카드 등록모드, 삭제모드, IDLE상태 추가
- DS1302 Real-time clock 데이터시트 코딩
- DS1302를 통해서 현재시각을 I2C LCD에 출력
- Comportmaster를 통해서 현재시각 수정
